Student Expense Tracker

1. Project Description

Student Expense Tracker is a simple web application developed using HTML and CSS.

It helps students record, manage, and track their daily expenses.

2. Technologies Used

* HTML – To create the structure of the website.
* CSS – To design and style the webpage.

3. Features

* Add daily expenses.
* Enter expense name and amount.
* Select expense category.
* Display all expenses.
* Calculate total expenses.
* Delete expenses.
* Filter expenses by category.
* Validate user inputs.
* Responsive user interface.

4. Expense Categories

* Food
* Travel
* Shopping
* Education
* Other

7. Working

Users enter an expense name, amount, and category. JavaScript adds the expense to a list and automatically calculates the total amount.

Users can also delete expenses and filter them according to categories.

8. Conclusion

The Student Expense Tracker is a beginner-friendly project that helps students understand HTML, CSS, JavaScript, and DOM manipulation while learning how to manage daily expenses.
